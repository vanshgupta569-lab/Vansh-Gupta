# Marginalia Research & Financial Terminal

An institutional-grade financial research platform and interactive 3-statement DCF valuation workspace designed for rigorous fundamental analysis, audited historical statement tracking, driver-based projections, and target fair value calculations.

---

## 🌟 Key Features

- **Etymology & Philosophy**: Highlighting the core thesis of institutional margin analysis and accounting precision.
- **Company Directory & Screening**: Searchable coverage universe spanning global large-cap equities (e.g., Reliance Industries, TCS, HDFC Bank, Infosys, ICICI Bank, Apple, Microsoft, NVIDIA, Alphabet, Amazon).
- **Company Specific Analysis**:
  - **Historical Financials**: Multi-year audited Income Statement, Balance Sheet, and Cash Flow Statement metrics.
  - **Forecasted Financial Statements**: Dynamic 5-year 3-statement forward model driven live by custom driver assumptions.
  - **Driver Assumptions Workspace**: Customizable Revenue Growth, Operating Margin, Tax Rate, Capex % of Revenue, Terminal Growth Rate, and WACC sliders.
  - **DCF Model & Valuation Output**: Interactive Discounted Cash Flow valuation, enterprise-to-equity bridge, target fair value price, and automated **BUY / HOLD / SELL** verdict badge with detailed analyst commentary.

---

## 🛠 Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS v4, Lucide React Icons, Motion animations.
- **Build & Runtime**: Vite, Node.js, Express.

---

## 🚀 Getting Started

### Prerequisites

- **Node.js**: v18.0.0 or higher
- **npm**: v9.0.0 or higher

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd <repository-directory>
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:3000`.
